# 현재 확정 설계

이 문서는 인터뷰로 정리한 최신 요구사항이며 초기 기획 문서와 다를 때 우선합니다.

## 실행과 저장

정적 HTML 하나에 UI/CSS/JS/가상 샘플을 포함합니다. HTTP 서버는 실행 필수 조건이 아닙니다.
file://에서는 fetch 없이 내장 가상 샘플을 보여주고, 사용자가 승인한 폴더 또는 선택적인 Git 도구에서 실제 파일을 읽습니다.
Pages는 상대경로로 JSON/MD/이미지를 읽고 수정은 메모리에서 처리합니다. 변경 파일은 경로를 보존한 ZIP으로 내립니다.
로컬 폴더는 파일별 원본 바이트를 저장 전 비교합니다. 다른 편집자의 변경이 있으면 덮어쓰기를 중단합니다.
Git 연결 도구는 파일 저장, diff 검토, 지정된 데이터 경로 커밋 및 일반 push를 담당합니다.

## 도메인

Task 하나가 루트 또는 하위 작업입니다. parentId=null은 메인 과제, order는 형제 순서입니다.
계층 순환은 거부합니다. 추가 하위 작업, 마일스톤, 개발 로그, 의사결정, 릴리즈는 사용하지 않아도 됩니다.
진행률은 말단 작업에서 입력합니다. 상위 화면은 보관/취소되지 않은 말단 작업 평균을 표시하며 persisted progress 의미는 유지합니다.
일정은 사용자가 입력한 날짜를 사용합니다. 하위 일정으로 상위 시작/종료일을 자동 덮어쓰지 않습니다.
종료일은 완료일 때 actualEndDate 우선, 나머지는 targetEndDate입니다. 미정일은 거짓 날짜를 만들지 않습니다.
완료 상태에서도 actualEndDate는 선택 사항이며 사용자가 비운 값을 자동으로 채우지 않습니다.
간트 과제명 손잡이는 같은 상위 과제 안의 위·아래 순서를 바꾸고, 일정 막대의 좌우 드래그는 시작/목표/실제 종료일을 같은 일수만큼 옮깁니다. 마일스톤과 릴리즈 날짜는 별도로 유지합니다.
간트 막대의 마우스 오버/키보드 포커스에는 현재 상태와 가장 최근 로그·결정·마일스톤·릴리즈·변경 이력의 요약을 표시합니다.

## 데이터 계약

schemaVersion=1, 기존 필드 의미 유지. 추가 필드: parentId, order, bodyFile, images, archived, history.
web/data/index.json은 전체 목록, tasks/TASK-ID.json은 구조화된 정보, notes/TASK-ID.md는 본문입니다.
images/TASK-ID/고유파일명.ext에 실제 이미지 바이트를 둡니다.
폼은 description/checklist/images 관리 주석 영역을 MD에 기록합니다. 외부 영역과 알 수 없는 JSON 필드는 보존합니다.
전체 Markdown/Notion 블록 에디터가 아니라 폼 기반 문서 편집기입니다.
보관과 이미지 참조 제거는 기존 파일을 물리 삭제하지 않습니다. 복구와 장기 보존을 우선합니다.
보관된 과제는 전용 필터로 따로 조회하고 복구할 수 있습니다.
삭제는 선택한 과제와 모든 하위 작업을 index에서 제거합니다. 기존 파일은 Git 복구를 위해 고아 파일로 남기며, 새로 만들고 아직 저장하지 않은 파일만 메모리에서 제거합니다.

## 공개와 협업

공개 저장소에는 가상 샘플만 둡니다. 실제 업무는 별도 비공개/사내 저장소에서 운영합니다.
현재는 단일 편집자 기준이며 향후 팀 작업은 각자 clone/pull → 편집 → push, 충돌은 Git에서 명시적으로 해결합니다.
원격 저장소에 직접 쓰는 정적 Pages API는 제공하지 않습니다. 별도 인증 backend 없이는 안전한 영구 웹 저장이 불가능합니다.
