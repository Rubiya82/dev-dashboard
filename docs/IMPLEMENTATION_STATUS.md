# 구현 및 검증 현황 · 2026-09-10

## 구현

독립 실행 HTML 두 개, 계층형 과제 관리, 폼 편집/미리보기, MD·JSON 분리, 이미지,
간트, 개발/의사결정/마일스톤/릴리즈 기록, ZIP 다운로드, 폴더 직접 저장,
선택적인 Python 로컬 Git 저장·커밋·푸시 도구가 구현되어 있습니다.

## 검증 완료

- Python 통합 테스트 12개 통과: 임시 Git 저장소 + bare remote에 실제 저장·커밋·푸시 및 재시도.
- 외부 파일 충돌, 오래된 diff 승인, 무관한 staged 파일 차단, unstaged 파일 제외, 경로/Origin/token 검사.
- 브라우저 테스트 15개 통과: 실제 JS 데이터 처리, MD 보존, ZIP CRC, 이미지, 폴더 API 모형, 폼, XSS, 계층, 보관·복구, 드래그, 기록 폼.
- 300/500개 과제 실제 목록·간트 DOM 렌더링. 500개 약 0.16~0.48초 (반복 실행 참고 수치).
- 390/768/1024/1280 너비에서 페이지 바깥 가로 넘침 없음.
- 파일 저장 권한 거부/외부 변경은 API 모형으로 검증. 실제 사용자 폴더 권한 승인은 미검증.
- 도구의 file:// URL 정책으로 직접 더블클릭 브라우저 검증은 수행하지 못했습니다.

기존 PowerShell의 문자열 검색 기반 검사는 실제 JS/저장 로직의 기능 검증을 대신하지 못하므로 교체했습니다.

## 호환성 및 한계

schemaVersion 1 유지, 기존 필드와 알 수 없는 JSON 필드 보존, 새로운 필드는 additive입니다.
과거 본문 없는 JSON도 읽을 수 있고 편집 시 MD를 생성합니다.
임의 Markdown 문법 전체를 WYSIWYG 변환하지 않습니다. 폼 관리 영역 밖 문서는 보존하되 화면 미리보기에는 포함하지 않습니다.
폴더 직접 저장은 파일별 저장으로, 다중 파일 전체 트랜잭션이나 완전한 동시 편집 잠금은 아닙니다.
로컬 도구의 기존 파일 백업은 .dashboard-backups에 남습니다.
새로고침 전 미저장 경고가 있으며, 브라우저 크래시 복구용 자동 저장은 제공하지 않습니다.
팀 실시간 공동 편집, 자동 Git 병합, Pages 자체 인증 저장은 향후 범위입니다.

공개 사이트 배포 상태는 GitHub Pages 설정/최신 배포 결과에서 확인합니다.
