# 05. 운영 흐름 (현재)

현재 확정 사항은 [14_CURRENT_DESIGN.md](14_CURRENT_DESIGN.md)를 우선합니다.

## Pages

접속 → 폼 편집 → 변경 적용 → 변경 ZIP → 저장소 루트에 압축 해제 → diff 확인 → commit/push.
ZIP은 web/data 경로를 보존합니다. 다운로드를 디스크 저장 또는 Git 반영 완료로 표시하지 않습니다.
아무 방문자나 화면에서 샘플을 편집할 수 있지만, 방문자의 메모리 변경이 원격 파일에 저장되지는 않습니다.

## 로컬

index.html 더블클릭 → 작업 폴더 선택/권한 승인 → 실제 파일 읽기 → 폼 편집 → 로컬 저장.
HTTP 서버는 기본 실행에 필요하지 않습니다. API 미지원/권한 거부 시 ZIP으로 보관합니다.
Git 연결 도구를 사용하는 경우 도구 실행 → 연결 → 폼 편집 → GitHub 반영 → diff 확인 → 저장·커밋·푸시.

## 팀 작업

현재는 단일 편집자 기준입니다. 팀원은 각자 clone/pull 후 편집하고 작은 단위로 push합니다.
동시 편집 자동 병합/실시간 동기화는 지원하지 않습니다.
외부 파일 변경은 저장 전 감지하여 중단하며, 원격 선행 변경은 Git 도구에서 pull/충돌 해결을 요청합니다.
