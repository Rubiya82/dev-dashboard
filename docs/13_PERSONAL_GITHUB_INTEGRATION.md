# 개인 GitHub 배포

대상 저장소: https://github.com/Rubiya82/dev-dashboard
대상 사이트: https://rubiya82.github.io/dev-dashboard/

사용자가 저장소와 Pages 모두 공개로 변경하도록 승인했습니다.
실제 과제명은 포함하지 않고 일반적인 가상 샘플 10개만 게시합니다.
개인 업무/사내 데이터는 이 공개 저장소와 분리해야 합니다.

브라우저의 도메인·경로는 상대경로 기반이며 GitHub.com/Enterprise 공통입니다.
Git 연결 도구는 선택한 로컬 clone의 origin과 현재 브랜치를 사용합니다.
GitHub REST API/PAT을 요구하지 않습니다.

정적 파일 Pages는 인증 없이 Git 저장소에 쓰기를 수행할 수 없습니다.
직접 웹 저장은 인증된 별도 backend 또는 승인된 API 설계가 필요하므로 현재는 제공하지 않습니다.
