# 06. 현재 UI / UX

메인 목적은 과제 관리입니다. 좌측 메인 과제 탐색, 중앙 계층 목록, 간트 전환, 요약 KPI를 제공합니다.
과제별 편집 창은 기본 정보 / 상세 내용 / 개발 로그 / 의사결정 / 마일스톤 / 릴리즈 / 변경 이력으로 구성합니다.

- 메인 과제·하위 작업·추가 하위 작업은 동일한 데이터 구조입니다.
- 드래그 손잡이로 이동합니다. 행 위/아래는 형제 순서 변경, 중앙은 하위 작업으로 이동입니다.
- 키보드 사용자는 위/아래 버튼 및 상위 과제 선택 폼으로 재배치합니다.
- 검색/필터 중 드래그를 사용하지 않습니다.
- Markdown 소스 편집기는 없습니다. 일반 텍스트·체크리스트·이미지 폼과 문서 미리보기를 제공합니다.
- 보관하기는 비파괴 처리이며 보관함 포함으로 다시 표시할 수 있습니다.
- 변경 적용, 디스크 저장, GitHub 반영 상태를 구분합니다.
- Dark theme, 명시적인 상태 텍스트, 진행률 숫자, native 버튼/label, 키보드 focus를 사용합니다.
- 작은 화면은 2열 KPI·1열 폼, 목록/간트 내부 가로 스크롤을 사용합니다.
