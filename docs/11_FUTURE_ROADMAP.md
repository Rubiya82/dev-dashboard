## Optional analytics

- category별 진행 과제 수
- release cadence
- blocked duration

실제 개발 시간을 자동 추정해 사실처럼 저장하지 않는다. 사용자가 명시적으로 기록하거나 Git activity에서 파생한 값은 출처를 구분한다.
